# BarberBook

A mobile app that helps customers and barbers manage haircut appointments by showing barber availability and saving hairstyle preferences.

## Problem statement

Customers and barbers are affected by the lack of an easy way to manage haircut appointments. Customers cannot tell when a barber is available, and they often forget the hairstyles they want or had before, which makes it hard to explain what they need. This causes wasted time, miscommunication, and frustration for both sides. A mobile app that shows barber availability and saves hairstyle preferences would make the experience easier for both users.

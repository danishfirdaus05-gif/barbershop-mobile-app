# Requirements

## Functional requirements (what the system must DO)

1. The system shall allow customers to register and log in to their account.
2. The system shall display the availability of barbers in real time.
3. The system shall allow customers to book, change, and cancel a haircut appointment with a chosen barber.
4. The system shall allow customers to save and view their preferred hairstyles.
5. The system shall allow barbers to set their working hours and view their upcoming appointments.





## Non-functional requirements (how the system must PERFORM)

1. The system shall load the barber availability list within 3 seconds.
2. The system shall protect user passwords and personal data by storing them in encrypted form.
3. The system shall have a simple interface so that a new user can book an appointment in 5 steps or fewer.

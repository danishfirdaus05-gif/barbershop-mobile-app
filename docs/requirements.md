# Requirements

## Functional requirements
- FR1: The system shall allow customers to register an account using an email and password.
- FR2: The system shall allow registered customers to log in.
- FR3: The system shall display each barber's available time slots for a selected date.
- FR4: The system shall allow customers to book an available time slot with a chosen barber.
- FR5: The system shall allow customers to cancel an existing appointment.
- FR6: The system shall allow customers to save their preferred hairstyles.
- FR7: The system shall allow barbers to set their working hours.
- FR8: The system shall allow barbers to view their upcoming appointments.

## Non-functional requirements
- NFR1 (Performance): The barber availability list shall load within 3 seconds.
- NFR2 (Security): The system shall store passwords as salted hashes and transmit data over HTTPS.
- NFR3 (Usability): A new user shall be able to book an appointment in 5 steps or fewer.

# User Stories

Format: As a \[type of user], I want \[goal], so that \[reason or benefit].





1. As a customer, I want to see which barbers are available, so that I can book a haircut at a time that suits me without wasting time.
2. As a customer, I want to save my favourite hairstyles in the app, so that I can show my barber exactly what I want and not forget it.
3. As a barber, I want to set my working hours and view my upcoming appointments, so that customers know when I am available and I can manage my schedule easily.
4. As a customer, I want to change or cancel my appointment in the app, so that I can adjust my plans without having to call or message the barber.

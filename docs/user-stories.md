# User stories

## US1 (links to FR3)
As a customer, I want to see which barbers are available, so that I can book a haircut at a time that suits me without wasting time.

Acceptance criteria:
1. Selecting a barber and a date shows only that barber's open time slots for that date.
2. A time slot that has already been booked no longer appears as available.

## US2 (links to FR6)
As a customer, I want to save my favourite hairstyles in the app, so that I can show my barber exactly what I want and not forget it.

Acceptance criteria:
1. A customer can save a hairstyle with a name and a short description.
2. Saved hairstyles still appear in the customer's list after logging out and back in.

## US3 (links to FR7)
As a barber, I want to set my working hours, so that customers only book when I am available.

Acceptance criteria:
1. A barber can set start and end times for each working day.
2. Customers can only see and book time slots within the barber's set working hours.
